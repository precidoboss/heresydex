HERESY DEX Docs

HERESY DEX is a no-backend frontend for trading on The Grotto — an Avalanche L1 — and for moving value between The Grotto and Avalanche C-Chain. Everything you see is read straight from the chain; every action is a transaction you sign yourself.

⇄ SwapTrade any listed token through one router. 🌉 BridgeSend to Avalanche with an optional auto-swap. ◔ PortfolioBalances, USD values and history.
ℹ️

Non-custodial. HERESY DEX never holds your funds or keys. The site is static HTML/JS; it talks to your wallet and to public RPC / explorer endpoints.

Quick start

  1. Open the app and press Connect Wallet. If you have several browser wallets (Core, MetaMask…), HERESY DEX lists them all — pick one.
  2. Approve the network switch. The app asks your wallet to switch to The Grotto (chain ID 36463) and adds it if it's missing.
  3. Choose tokens in the swap card, enter an amount, and check the rate, price impact and minimum received.
  4. Confirm. For ERC-20 inputs you sign an approval first, then the swap. Native HERESY needs only the swap.
💡

You need a little native HERESY on The Grotto for gas, even when swapping other tokens.

Swapping

Every listed token has a pool against WHERESY (wrapped HERESY). The HeresyRouter handles routing so you always sign a single swap transaction:

TOKEN A→WHERESY→TOKEN Btwo-hop, when neither side is HERESY/WHERESY
  • Direct: HERESY/WHERESY ⇄ token uses a single pool.
  • Wrap / unwrap: HERESY ⇄ WHERESY is 1:1 with no fee. The router wraps and unwraps native HERESY automatically.
  • Approvals: for ERC-20 inputs the app approves exactly the amount you are swapping — not unlimited.
  • Deadline: each swap is valid for 20 minutes; after that the router rejects it.
  • Estimates: quotes come from the router's on-chain quote() view, refreshed as you type.

Reading the swap details

FieldMeaning
RateExpected output per 1 unit of the input token for your size.
Price impactHow far your trade moves the pool price versus spot. High on thin pools.
Min. receivedOutput × (1 − slippage). If the pool moves further than this before your transaction lands, it reverts.
Platform fee1% of the input on routed swaps; none for wrap/unwrap.
⚠️

Tokens tagged thin have very little liquidity. Even small trades can move the price a lot — check Price impact before signing.

Charts & prices

The price chart and the Markets table are built from on-chain data, so they work for every visitor on the first load.

Where the numbers come from

  • History (7 days): every pool is a constant-product pair that emits a Sync(reserve0, reserve1) event on each trade or liquidity change. On load, the app reads those logs from the Grotto RPC and turns each into a price point (WHERESY reserve ÷ token reserve). New events are fetched incrementally and cached in your browser.
  • Live ticks: reserves are polled every 20 seconds and appended to the series.
  • USD values: BOB's USD price is read from a DEX aggregator reference pair on Avalanche; HERESY's USD price is derived from the BOB pool's ratio; every other token is priced through its WHERESY pool.

Chart controls

  • Token tabs switch the pair. HERESY / WHERESY are shown in BOB terms, since they are pegged to each other.
  • Token / USD≈ toggles the unit. USD mode multiplies historical prices by the current HERESY/USD rate, so it is an approximation — Token mode is exact.
  • 1H · 6H · 24H · 7D · ALL choose the window. A flat line simply means no trades moved the pool in that window.
  • Click any row in Markets to chart it and pre-load a HERESY → token swap.
ℹ️

If the RPC refuses large log queries, the app shrinks the request size automatically; if it still fails, the chart falls back to live ticks and says so under the chart.

Bridging

The Bridge page has two modes.

Swap & Bridge (recommended)

Any token on Grotto→GrottoBridgeHub→Warp / ICTT→AvalancheBridgeReceiver→Final token on Avalanche
  1. You send any HERESY DEX token. BOB, CAVE, USDC and native HERESY are bridged directly. Any other token is first swapped into BOB, CAVE or USDC on The Grotto (you choose which under Bridge via).
  2. Final token on Avalanche defaults to the bridged asset itself. Pick another token (or paste a custom address) and the receiver swaps into it on arrival.
  3. Recipient defaults to your connected wallet; paste another address to send to someone else.
  4. Slippage applies to both legs (the Grotto swap and the Avalanche swap).

The Avalanche-side swap is routed through the KyberSwap aggregator API; the app requests a route, builds the calldata, and passes it to the receiver so it can execute for you.

Funds usually arrive on Avalanche shortly after the Grotto transaction confirms. Check the recipient address on Snowtrace.

Raw Bridge ($BOB only)

Sends a direct send() to the ERC20TokenHome contract using the standard ICTT interface. The destination blockchain ID is read live from Avalanche's Warp precompile rather than hard-coded. Advanced settings let you adjust the required gas limit and a relayer fee in BOB.

⚠️

Bridging is not instant and cannot be cancelled once sent. Always double-check the recipient address, and test with a small amount first.

Portfolio

  • Holdings: live balances for every listed token, valued in USD and shown as a share of your total. Sell jumps to Swap with the token and full balance pre-filled (you still confirm). Send opens a direct transfer on The Grotto.
  • Transaction history: swaps and bridges made through this app. Stored only in your browser (localStorage) — clearing site data removes it. Nothing on-chain is affected.
  • On-chain activity: every transaction for your address on The Grotto, loaded from the Grotto block explorer's API.

Fees & slippage

CostWho gets itDetails
Platform feeHeresyRouter1% of the input on routed swaps. Wrap/unwrap is free.
Price impactThe pool curveDepends on pool size versus your trade size. Shown in the swap details.
Network gasValidatorsPaid in native HERESY on The Grotto (and AVAX only if you transact on Avalanche yourself).
Relayer feeWarp relayerRaw Bridge only, optional, set in advanced settings. Default 0.

Slippage is the maximum adverse price move you'll accept between quote and execution. Presets are 0.5%, 1% and 3% for swaps; 1%, 2% and 5% for Swap & Bridge. Higher values succeed more often but let a trade fill at a worse price.

Security & risks

  • You sign everything. The app can't move funds without a wallet confirmation. Read what your wallet shows.
  • Exact approvals. Token approvals are limited to the swap amount, so a leftover allowance can't be drained later.
  • Thin liquidity. Small pools can be manipulated and may have large price impact. Treat thin markets as high-risk.
  • Smart-contract risk. The router, hub, receiver and pools are on-chain code. Bugs are possible; only trade what you can afford to lose.
  • Third parties. The Avalanche leg depends on the KyberSwap API, USD references on a DEX data API, and history on the Grotto RPC and explorer. If one is down, the related feature degrades — your funds are not at risk from a data outage.
  • Local data. Price cache and your local transaction list live in your browser's localStorage. They contain no keys.
⚠️

Never share your seed phrase or paste a private key or access token into any website — including this one. HERESY DEX will never ask for them.

Troubleshooting

"Price moved past your slippage tolerance"

The pool changed between your quote and execution. Retry, or raise slippage a little (especially on thin tokens).

"No route" or "Not enough liquidity"

The pair has no pool path, or the pool can't fill that size. Try a smaller amount or route via HERESY.

My wallet isn't listed

Reload after installing the extension. Wallets announce themselves via EIP-6963; older wallets are detected through window.ethereum. Disable duplicate wallet extensions if two fight over the same provider.

The chart says "Live ticks only"

The Grotto RPC rejected the log query. The chart still fills from live ticks every 20 seconds; history retries every 10 minutes.

Balance shows "–" after connecting

Make sure your wallet is on The Grotto (chain ID 36463). Switch networks and press Refresh in Portfolio.

My bridge hasn't arrived

Wait a few minutes after the Grotto transaction confirms, then check the recipient address on Snowtrace.

FAQ

Is HERESY DEX custodial?

No. There is no backend and no account. Your wallet signs every transaction.

What's the difference between HERESY and WHERESY?

WHERESY is wrapped HERESY (an ERC-20). They are exchangeable 1:1; the router wraps and unwraps for you.

Why is the USD chart "approximate"?

Historical USD is computed with today's HERESY/USD rate because the app doesn't store historical USD feeds. Token mode (priced in HERESY or BOB) is exact.

Where is my transaction history stored?

Swaps and bridges you make here are saved in your browser only. The "On-chain Activity" list is fetched live from the explorer and isn't stored.

Can I list my token?

A token needs a pool against WHERESY and a registration on the router. See Adding a token.

Deploy

Any static host works (Vercel, GitHub Pages, Netlify). Point it at the repo root — there is nothing to build.

Adding a token

  1. Create a WHERESY pair for the token on The Grotto's DEX.
  2. Register that pool on HeresyRouter with setPool(). The frontend and router must agree about what is swappable.
  3. Add an entry to TOKENS in assets/js/config.js:
MYTOKEN: {
  symbol: 'MYTOKEN', type: 'erc20',
  address: '0x…token', decimals: 18,
  pool: '0x…pair',        // WHERESY pair address
  lowLiq: true,           // optional: shows the "thin" warning
  icon: 'https://…/logo.png'
},

The token menu, Markets table, chart tabs, Portfolio and this docs page's token table all update from that one entry. A generated letter icon is used if you omit icon.
